## 1. One script, two lanes

`infra/vps/web-dispatch/web-dispatch.sh` and `run-chunk.sh` are now parameterized. **Every default is
the website lane's original value**, so `jahjah-web-dispatch` — whose unit passes no
`EnvironmentFile` — resolves exactly what it resolved before. The ERP lane is the same code with
`erp-dispatch.env`.

**The proof, from the LIVE installed copy, not from the source:**

```
$ LANE_PRINT_CONFIG=1 /opt/jahjah/web-dispatch/web-dispatch.sh
JJ_JOB=web-dispatch            JJ_OFF=/opt/jahjah/WEB_DISPATCH_OFF
REPO=obidex/jahjah-website     TMUX_SESSION=web       WORKTREE=/opt/jahjah/web
CHUNKS=/opt/jahjah/chunks      DAILY_CAP=3            CHUNK_TIMEOUT=25200
HEARTBEAT=…/HEARTBEAT-web-dispatch.md                 HEARTBEAT_EVERY=3000
```

Every value matches the literals the script carried before parameterization. The ERP lane resolves
`JJ_JOB=erp-dispatch`, `ERP_DISPATCH_OFF`, `obidex/jahjah-internal`, tmux `jahjah`,
`/root/jahjah-internal`, `/opt/jahjah/chunks-erp`, `HEARTBEAT-erp-dispatch.md` — same caps.

**The website timer was never stopped or restarted.** A poll re-reads the script on its next run, and
both live files were replaced **atomically** (temp + `mv`) so any running process keeps its old inode.

**The directory keeps the first instance's name.** Renaming it would change the website unit's
`ExecStart`, and that unit must not be touched. A misleading directory name is a smaller price than
editing a live lane; the README says so at the top.

## 2. Smoke test — from the TIMER, never by hand

The label gate was tested first, then the start:

| Step | Time (UTC) | Result |
|---|---|---|
| Issue #95 created as `chunk:proposed` | 08:09 | **ignored for 3 polls** — the label is the gate |
| Relabelled `chunk:approved` | 08:12:42 | — |
| Lane picked it up | **08:13:08** | **26 seconds**, well inside the 10-minute limit |
| tmux window | 08:13:08 | `jahjah:chunk-95` opened |
| The session's own comment | 08:13:1x | **`smoke ok`** |
| Exit | 08:13:16 | `exit 0 after 8s` |
| Dispatcher comment | 08:13:16 | `dispatcher: exit 0, 8s` |
| Final label | 08:13:18 | **`chunk:failed`** |

**`chunk:failed` is the expected outcome here and is not a failure of the lane.** That label means
"the process exited without the chunk posting a final report", and the smoke chunk was deliberately
told to post only a comment and stop. It is the fallback working. A real chunk moves itself to
`chunk:done` or `chunk:blocked` through its own reporting.

Counters afterwards: `chunks today 1 of 3`, `in-flight absent`, `strikes 0`,
`last-result ok: dispatched chunk #95 (opus)`. The console log stayed on the box, mode 600 inside a
mode-700 directory. The issue was closed.

## 3. What the two lanes do NOT share — worth knowing before chunk 5

- **Concurrency is capped PER LANE, not per box.** Each refuses a second chunk of its own; nothing
  stops one chunk per lane running at once — two full sessions, two working trees, one machine. That
  is allowed. `HEALTH-daily.md` now raises **two open `chunk-*` windows** as an attention item so it
  is visible rather than discovered.
- **The ERP lane runs from `/root/jahjah-internal`** — the same tree an interactive session uses. The
  website lane has `/opt/jahjah/web` to itself. The lane stops a second *chunk*; it cannot stop a
  person working in that tree at the same time.
- **The timers are staggered** — website on even minutes, ERP on odd. They share one relay lock, so
  neither waits on the other's publish.

## 4. The label gate, stated exactly

Labelling an issue needs **at least Triage**, not write access. So the gate is "someone the owner has
granted at least Triage on a private repository", and its strength is the collaborator list — an
**external invariant this box cannot enforce**. Re-checked at this chunk's preflight:

```
$ gh api repos/obidex/jahjah-internal/collaborators --jq '.[].login'   -> obidex
$ gh api repos/obidex/jahjah-internal/invitations --jq 'length'        -> 0
```

`D230` records this as the general rule the two chunks paid for: **a control resting on metadata, a
label or a self-asserted identity is a convention, not a boundary, and must be written down as an
assumption about an external system rather than a property of ours.**

## 5. Also done here

- **`publish-report.sh` accepts `JJ_JOB` from the caller** (default `session`), so two lanes
  publishing concurrently no longer interleave in one log. Its README already prescribed this. The
  relay itself was never at risk — the shared flock is taken per invocation regardless.
- **`HEALTH-daily.md` reports both lanes from one function**, with the heartbeat age that separates
  an idle lane from a dead one, the in-flight marker age that catches a wedge, and the cross-lane
  window count.
