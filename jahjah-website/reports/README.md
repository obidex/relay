# Relay — `jahjah-website`

<!-- index: what this folder is and who writes to it -->

Machine-written reports about the **public website project** (`obidex/jahjah-website`), published
here so they can be read without a login and without access to that private repo.

**Everything in this folder is world-readable and permanent.** It is a public git repository; a file
deleted later stays in the history. Nothing is written here that depends on staying private.

**The reports are read-only observations.** The job that writes them never pushes to the website
repo, never edits its files, never touches Vercel or Sanity, and never applies a fix. Every problem
it finds is written down and left alone.

| File | Written by | Cadence |
|---|---|---|
| `TRUTH-weekly.md` | `jahjah-web-truth` on the VPS work engine | Mondays 05:30 UTC, overwritten in place |

`INDEX.md` is regenerated from disk on every publish. Read it rather than listing this folder
through the GitHub API.

**If `TRUTH-weekly.md` is more than about nine days old, the job has stopped** — treat everything on
it as history, not as current state. What the job does and how to turn it off is in
`docs/runbooks/automations.md` in `obidex/jahjah-internal`.
