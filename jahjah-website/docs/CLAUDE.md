`AGENTS.md` above is the rulebook and binds every session. This file adds only what is Claude-specific.

## How work runs
Work runs in the Claude Code Project `jahjah-website`: the coordinator plans, writes cards and starts threads (`/strategist`); each thread runs its cards with `/run-card`, which is the contract. A card is a GitHub issue from `.github/ISSUE_TEMPLATE/card.yml`; load only the skills it names (`run-card`, `migrate-db`, `milestone-review`, `strategist`, `verify`, `ship`). `docs/STATE.md` holds everything volatile (phase, flags, ledger, owner decisions, next step). `docs/DECISIONS.md` is append-only, at most two lines per `W###`. `docs/reference/site.md` is generated by `npm run reference`, never hand-edited. `docs/archive/` is never loaded. Open follow-ups are `backlog` issues. One home per fact: point to it, don't copy it. A thread's last message opens with `DONE`, `WAITING FOR YOU (exact action)` or `STOPPED (why)`, and its last line repeats it.

## Harness
- Hooks live in `scripts/dispatch/hooks/` and are wired by `.claude/settings.json`: `pre-bash` refuses destructive and owner-only commands and any push reaching `master`; `post-edit` type-checks `.ts` and syntax-checks `.js`/`.mjs`/`.sh`. Fix what `post-edit` reports before the next edit. A hook is project-level only, passes `bash -n` before it lands, and changes through a PR, never edited in place (W107, W115).
- No session edits `.claude/settings.json`: change `scripts/dispatch/settings.v3.json` in a card's PR, and the owner copies it into place (W138). Nothing of ours goes in user-level `~/.claude`. Never run `claude setup-token` (W100).
- Owner-run only: copying `settings.v3.json` into `.claude/settings.json`, entering or rotating secrets, and destructive `gh api` calls (label or branch deletes). `supabase db push` goes to the thread after GATE 1 approval (W179); until `pre-bash` and the settings allow it, the thread posts the exact line and the owner runs it.
- The `reviewer` agent is `.claude/agents/reviewer.md`; a security review runs on Opus.
