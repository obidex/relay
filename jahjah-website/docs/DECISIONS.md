- **W097** [2026-09-02] LESSON. **`grep -q` at the end of a pipeline inverts its own test under `set -o pipefail`.** `grep -q` exits on its first match, closing the pipe; the producer dies of SIGPIPE (141); `pipefail` promotes that to the pipeline's status. `jahjah-web-backup`'s first run deleted a valid 63 KB Sanity export reporting "no data.ndjson in the archive". It is invisible on small inputs — a toy reproduction with `cat` and three lines returns 0, because the producer finishes before the reader exits — so it only appears against the real artefact, which is why an automation's first run must come from its timer against real data. Use `grep -c` and compare the count, or capture the output and test the variable. The mirror image of the `grep -c` counts-lines-not-matches trap.
